# ShipNex Brand Assets

Place your official ShipNex logo files here:

- `shipnex-logo.png` — Main logo (use in Header, Footer, Login, Admin)
- `shipnex-logo-white.png` — White version for dark backgrounds
- `shipnex-icon.png` — Icon only (use for favicon)
- `favicon.ico` — Browser tab icon

## Logo Usage Guidelines

- **Primary logo**: Use on light backgrounds (white, light gray)
- **White logo**: Use on dark backgrounds (navy `#1a237e`)
- **Minimum size**: 120px width for header, 160px for login page
- **Clear space**: Maintain padding equal to the height of the "S" in ShipNex

## Brand Colors

| Color | Hex | Usage |
|-------|-----|-------|
| Deep Navy | `#1a237e` | Primary, headers, footer |
| Bright Blue | `#0d47a1` | Gradients, accents |
| Orange | `#ff6f00` | CTAs, highlights, badges |
| Green | `#2e7d32` | Success states |
| White | `#ffffff` | Backgrounds, text |
